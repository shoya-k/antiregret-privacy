AntiRegret プライバシーポリシー

最終更新日: 2026年10月9日

AntiRegret(以下「本アプリ」)は、個人開発者が提供する iOS アプリです。本アプリは、利用者の情報を収集しません。このページでは、本アプリが何を扱い、何を扱わないかを説明します。

1. 収集する情報

本アプリは、利用者の情報を一切収集・送信しません。

  • 利用者登録(アカウント作成)はありません
  • 利用者を識別する ID を作成しません
  • 広告・解析(アクセス解析、行動ログ)・クラッシュレポートの SDK を組み込んでいません
  • 開発者が利用者のデータを閲覧する手段はありません

2. 端末の中に保存される情報

本アプリで入力・記録した内容は、すべて端末内のデータベース(SQLite)に保存されます。端末の外に送信されることはありません。

保存されるもの内容
メモ動画の URL・タイトル・メモ本文、金言の本文・出典・メモ
タグ利用者が作成したタグの名前
再会の記録「実行した / 後回し / スキップ」などの操作と、その日時
リマインドの日時利用者が設定した通知の日時

これらは本アプリのアプリ内領域にのみ保存されます。本アプリのサーバーは存在しません。

3. 通知について

本アプリの通知はすべて端末内で作られるローカル通知です。通知の内容が外部のサーバーを経由することはありません。通知は、iOS の設定アプリからいつでも停止できます。

4. 外部サービスへのリンク

保存した動画を開くと、その URL に応じて Safari や各サービスのアプリ(Instagram、YouTube など)が起動します。移動先での取り扱いは、各サービスのプライバシーポリシーに従います。本アプリは、利用者がどの動画をいつ開いたかを外部に送信しません。

5. 第三者提供

本アプリは利用者の情報を収集しないため、第三者に提供する情報はありません。

6. データの削除

端末から本アプリを削除すると、保存されていたメモ・タグ・記録はすべて削除されます。開発者側に控えは残りません(そもそも送信されていません)。

7. 子どものプライバシー

本アプリは特定の年齢層を対象としていません。情報を収集しないため、子どもから情報を集めることもありません。

8. 本ポリシーの変更

本アプリの機能変更にあわせて、このポリシーを更新することがあります。変更した場合は、このページの最終更新日を改めます。
